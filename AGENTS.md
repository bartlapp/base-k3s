# Repository instructions

Before changing infrastructure procedures, context tools or qualification, read:

- [README](README.md) for the supported Base profile and operator path.
- The sibling [Bartl entry point](../bartl-app/AGENTS.md), its application contract and operating guide. If that checkout is unavailable, use the public [contract](https://github.com/bartlapp/bartl-app/blob/main/docs/application-contract.md) and [operating guide](https://github.com/bartlapp/bartl-app/blob/main/docs/how-to-bartlize.md).

Apply the shared operator-procedure and qualification standard to Base's infrastructure responsibility; application lifecycle requirements do not turn Base into an application controller. Package READMEs remain the owners of application operations.

Identify the governing revisions and relevant local changes. Honor an explicitly selected revision; do not switch to main automatically. Local guidance is not proof of publication or exercised behavior. Keep actual installation records, protected inputs and raw qualification output outside this product repository.
